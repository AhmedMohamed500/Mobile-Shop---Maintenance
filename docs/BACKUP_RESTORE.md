# النسخ الاحتياطي والاستعادة

## النطاق

قاعدة البيانات PostgreSQL هي المصدر التشغيلي للحسابات والعملاء وأوامر الصيانة والمدفوعات. ملفات CSV للتسليم أو التحليل وليست نسخة استعادة كاملة.

## المتطلبات

- PostgreSQL client tools بنفس الإصدار الرئيسي للخادم أو أحدث توافقًا: `pg_dump`, `pg_restore`, `psql`.
- `DATABASE_URL` من مخزن أسرار موثوق، ولا يكتب في الأوامر أو السجلات المشتركة.
- مساحة مشفرة تكفي لثلاث نسخ على الأقل.
- حساب نسخ احتياطي بأقل صلاحيات لازمة.

## إنشاء نسخة

في PowerShell على جهاز إدارة موثوق:

```powershell
$env:DATABASE_URL = Read-Host "PostgreSQL connection string"
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
pg_dump --format=custom --compress=9 --no-owner --no-acl --dbname "$env:DATABASE_URL" --file "repair-$stamp.dump"
Get-FileHash "repair-$stamp.dump" -Algorithm SHA256 | Out-File "repair-$stamp.sha256"
```

شفّر الملف قبل نقله. مثال 7-Zip AES-256:

```powershell
7z a -t7z -mhe=on -p "repair-$stamp.7z" "repair-$stamp.dump" "repair-$stamp.sha256"
```

أدخل كلمة المرور تفاعليًا ولا تحفظها في المستودع. انقل النسخة المشفرة إلى مخزن منفصل عن قاعدة البيانات مع وصول محدود وسجل تدقيق.

## الاستعادة

أنشئ قاعدة اختبار فارغة. لا تختبر الاستعادة فوق الإنتاج:

```powershell
$env:RESTORE_DATABASE_URL = Read-Host "Empty test PostgreSQL connection string"
pg_restore --clean --if-exists --no-owner --no-acl --exit-on-error --dbname "$env:RESTORE_DATABASE_URL" "repair-YYYYMMDD-HHMMSS.dump"
```

بعد الاستعادة شغل نسخة API مؤقتة بمفاتيح اختبار، ثم تحقق من عدد المراكز والفروع والعملاء وأوامر الصيانة والمدفوعات، وسجّل دخول مستخدم اختبار، وافتح أمر صيانة وتتبعًا وتقريرًا ماليًا. سجل تاريخ الاختبار واسم المنفذ والنسخة ونتيجتها.

## الاحتفاظ والأتمتة

- يومي: 7 نسخ.
- أسبوعي: 4 نسخ.
- شهري: 12 نسخة.
- نفذ نسخة قبل كل migration أو نشر يمس البيانات.
- فعّل النسخ التلقائي وPoint-in-Time Recovery من مزود PostgreSQL إذا كانت الخطة تدعمه، وراقب فشل المهمة.
- اختبر استعادة نسخة حديثة شهريًا؛ وجود ملف غير مستعاد لا يثبت صلاحية النسخة.

## أمن النسخ

شفّر أثناء النقل والتخزين، افصل كلمة التشفير عن الملفات، لا تضع dump أو `.env.local` في Git، راجع صلاحيات المخزن كل ربع سنة، واحذف النسخ المنتهية بسياسة موثقة. بيانات فتح الأجهزة مشفرة في الإنتاج وتحذف عند التسليم، لكنها قد توجد في النسخ القديمة حتى انتهاء مدة الاحتفاظ.

## حالة التسليم

الإجراء موثق وقابل للتنفيذ. لم تُنشأ أو تُستعد نسخة إنتاج في هذه الجولة، لذلك حالة اختبار الاستعادة **NOT TESTED** حتى ينفذه مسؤول البنية على قاعدة اختبار.
